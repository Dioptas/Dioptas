Dioptas documentation
=====================

The active application uses Rust, React and Tauri. Its native test suite uses
frozen independent numerical reference data and requires no Python environment.
The Qt application, its Python tests and its manual are preserved on
`legacy/qt <https://github.com/Dioptas/Dioptas/tree/legacy/qt>`_.
