Dioptas

This application processes diffraction images locally with Rust, Dioptrin and dioptrin-io. It requires no Python installation, source checkout, development server or internet connection. Keep the complete application together when moving it.

Start a measurement

  1. Open an image in Calibration. Check the detector assignment, pixel sizes and orientation. Ambiguous detector matches remain Custom; your explicit choice takes precedence.
  2. Load a calibration, enter geometry manually, or select a calibrant and pick diffraction peaks. Use Calibrate for a fresh fit and Refine to continue a fit. Undo/Redo retains the workflow history.
  3. Use Mask for manual shapes and masking plugins. Integration produces a pattern and cake with the current calibration, masks and corrections.
  4. Use Batch and Map for image series. Save a .dio project to retain configurations and owned data. Explicit exports create pattern, image or processed series files.

Bundled examples

Raw CeO₂ Pilatus image · Separate reference calibration · Molybdenum phase

The Example action opens the raw image without applying the reference calibration. Starting values are CeO₂, 0.406626 Å wavelength, 172 µm pixels and 200 mm distance. They are starting inputs, not a fitted solution.

Resources and notices

Calibrants, detector definitions and scientific reference metadata are embedded in the processor; inspectable copies of the applicable data and notices accompany this guide. Material records retain their individual sources and qualifications. Optional numerical dataset packages are not included.

Resource hashes and provenance · Dependency license index · Dioptas license

Fonts use the operating system. Images, icons, lookup tables and application code are bundled; the application does not download these at runtime. Optional custom actions run programs chosen by you; a Python script you configure still needs its own interpreter.

Compatibility

This is a migration build. Current format-2 projects are supported within the native scientific boundary. Historical project formats 0/1, some legacy transformed-detector projects, arbitrary Python plugins and unqualified detector options fail explicitly. Keep original projects and data. Fixture agreement does not certify every detector or calibration.
