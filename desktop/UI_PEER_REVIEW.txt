## New defects

### Confirmed defects

1. **N1. Editing a fit seed blocks Save .poni, contrary to what the UI says.**
   - **Where:** `fitDraftDirty` → `canSaveCalibration` (`App.tsx:1514-1530`, button at `:2708`).
   - **Trigger:** After a fit, change the Distance start value on Fit, then open Validate. Save .poni is disabled, but the status text at `App.tsx:1576` still says "Inspect fitted ring alignment and RMS, then save .poni." The button has no tooltip explaining why.
   - **Why it matters:** The Fit note at `CalibrationExtras.tsx:180-184` says seeds "do not change the current geometry until you calibrate." Blocking the save of that current geometry contradicts it.
   - **Fix:** Either stop blocking the save on seed edits, or explain the block in the button and the status line.
   - **Basis:** Code reading only; I didn't run it. If the block is intentional, the explanation is still missing.

2. **N2. The Batch heatmap's y-axis title is cut off when the plot is short.**
   - **Where:** `BatchHeatmap.tsx:243-248` draws the fixed string "Frame index (0-based)" centred on the plot without measuring it.
   - **Seen in:** integration-frame-validation.png (standard text, once the toolbar wraps) and batch-compact-large.png, both showing "…(0-base".
   - **Fix:** Use `measureText` and fall back to a shorter label such as "Frame (0-based)".

3. **N3. A ring label is hidden under the zoom badge.**
   - **Where:** `RasterView.tsx:584-586` keeps labels inside `plotWidth`, but the HTML 1× badge sits on top of that area.
   - **Seen in:** calibration-validate.png, where cake label "15" is partly covered.

### Minor confirmed gaps

4. **N4. Loading a .poni silently replaces an unapplied geometry draft.**
   - **Where:** `geometryDraft.ts:65-67` resets the draft whenever the model geometry changes.
   - **Trigger:** Edit values in the manual dialog, close it, then click Load .poni. Only `!ready` disables that button (`App.tsx:2723`). The edits are discarded without a prompt, despite the dialog's "stay in this session" wording.

5. **N5. `PathInput` gives no sign that a path is truncated.**
   - **Where:** `PathInput.tsx:22` uses `text-overflow: clip`, so a path starts mid-word ("mens/.codex/…") with no leading ellipsis.
   - It also only re-scrolls to the end when the value changes or on blur (`PathInput.tsx:15, 23-26`), not when the pane is resized.

### Optional enhancements (not defects)

- With large text, the compact Fit column shortens the Rotation 3 display to "−2.776… × 10⁻⁸". The exact value appears on focus.
- The toolbar symbols `AA`, `A`, `|` and the footer label "Click —" are still explained only in Help.
- The default in-plot legend position still overlaps curve peaks and the "A" cursor label (map-compact-large, batch-compact). Keeping the legend inside the plot and movable is your decision and isn't counted as a defect. A smarter default position would still help.
