# Independent HDF5 counts fixture

`counts-bitshuffle-lz4.h5` (10,224 bytes) and its JSON manifest are copied
unchanged from `dioptrin-io/tests/data`, originally generated by PhaseSmith's
`tools/generate_hdf5_test_fixture.py`. Copyright PhaseSmith contributors,
MIT license (see LICENSE). The manifest records source dtype, producer,
file checksum and independent decoded-frame checksums. Stored orientation is
preserved in that fixture; Qt's consumer flips rows.
